Put your final 16:9 thumbnails in this folder, e.g. `sodium.webp`, `potassium.webp`, `action-potential.webp`.

If your real thumbnail is not present, the gallery automatically displays a corresponding SVG preview from `fallback/`. The SVGs are bundled so the gallery never looks broken while you're adding your assets.

Every path can be changed in `data/videos.js` (the `thumbnail` field). PNG and JPEG are supported too.

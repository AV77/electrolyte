# Your Reveal.js decks go here

Each subfolder has a placeholder `index.html`, which you can replace with your real Reveal.js presentation.

Keep each deck's other files (scripts, images, styles) inside its own subfolder and use relative links. You can also point the `deck` field in `data/videos.js` to an HTML file elsewhere in this site.

The parent website displays the decks through iframes and its Fullscreen button expands the iframe container. Click the deck before using Reveal.js arrow keys.
